## Claude Code

Wszystkie zasady projektu znajdują się w zaimportowanym AGENTS.md, wspólnym dla wszystkich agentów. Ten plik zawiera wyłącznie mechanikę specyficzną dla Claude Code. Nie dopisuj tu zasad projektu; trafiają one do AGENTS.md.

- Import `@.ai/lessons.md` ładuje indeks wniosków automatycznie na początku sesji. To spełnia wymóg przeczytania go z AGENTS.md.
- Przy zadaniach wieloetapowych zaczynaj od trybu planowania. Dalej obowiązują zasady z AGENTS.md dotyczące zamiany planu w specyfikację.
