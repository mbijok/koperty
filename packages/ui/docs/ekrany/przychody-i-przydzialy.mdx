# Ekrany: Przychody i przydziały

Przychód zwiększa pulę, przydział przenosi środki z puli do koperty w danym miesiącu (US-14–US-16).

## Przychód

| Stan   | Story              | Co widać                                     | Źródło |
| ------ | ------------------ | -------------------------------------------- | ------ |
| Nowy   | `Przychód: nowy`   | kwota, data (dziś), opis                     | US-14  |
| Edycja | `Przychód: edycja` | zapisane wartości, „Zapisz zmiany”, „Anuluj” | US-15  |

Stany walidacji i odpowiedzi API: wzorzec „Formularz”.

## Przydział

| Stan              | Story                          | Co widać                                           | Źródło         |
| ----------------- | ------------------------------ | -------------------------------------------------- | -------------- |
| Zmiana przydziału | `Przydział`                    | obecna kwota w polu, „Pula po zapisie”             | US-16, PRD 4.4 |
| Pula poniżej zera | `Przydział: pula poniżej zera` | −200,00 zł z „Debet” i wyjaśnieniem; zapis możliwy | US-16          |
| Przyszły miesiąc  | `Przydział: przyszły miesiąc`  | miesiąc w etykiecie pola                           | US-16          |

## Użyte elementy

- Widoki: `IncomeForm`, `AllocationForm`.
