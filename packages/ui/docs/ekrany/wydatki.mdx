# Ekrany: Wydatki

Nowy wydatek, lista operacji miesiąca, szczegóły i edycja wydatku (US-17–US-20).

## Nowy wydatek (`/expenses/new`)

| Stan        | Story                   | Co widać                                                | Źródło       |
| ----------- | ----------------------- | ------------------------------------------------------- | ------------ |
| Pusty       | `Nowy wydatek`          | kwota, koperta, przełącznik podziału, data (dziś), opis | US-17, E3-Q4 |
| Z podziałem | `Nowy wydatek: podział` | dwie części, „Podzielono całą kwotę.”                   | US-18        |

Błędy, suma części i odpowiedzi API: wzorzec „Podział wydatku”.

## Operacje (`/operations?month=…`)

| Stan          | Story                     | Co widać                                                     | Źródło     |
| ------------- | ------------------------- | ------------------------------------------------------------ | ---------- |
| Z danymi      | `Operacje`                | przełącznik miesiąca, „Liczba operacji: 5”, dni z operacjami | US-20      |
| Pusty miesiąc | `Operacje: pusty miesiąc` | „Brak operacji w wybranym miesiącu”, powrót do bieżącego     | Q5, E3-P8  |
| Pusty budżet  | `Operacje: pusty budżet`  | „Brak operacji w tym budżecie”, „Dodaj wydatek”              | US-21      |
| Ładowanie     | `Operacje: ładowanie`     | szkielety, bez licznika                                      | E2-P12     |
| Błąd          | `Operacje: błąd`          | stan błędu, bez licznika                                     | WCAG 3.3.1 |

## Szczegóły wydatku (`/expenses/<id>`)

| Stan                           | Story                                       | Co widać                                          | Źródło |
| ------------------------------ | ------------------------------------------- | ------------------------------------------------- | ------ |
| Pełne dane                     | `Szczegóły wydatku`                         | opis jako `h1`, kwota, „Edytuj”, „Usuń…”, podział | US-19  |
| Nie istnieje albo brak dostępu | `Szczegóły: nie istnieje albo brak dostępu` | jeden komunikat, „Wróć do operacji”               | PT404  |

Usunięcie: wzorzec „Potwierdzenie usunięcia”.

## Edycja wydatku (`/expenses/<id>/edit`)

| Stan                           | Story                                    | Co widać                                                            | Źródło            |
| ------------------------------ | ---------------------------------------- | ------------------------------------------------------------------- | ----------------- |
| Ładowanie                      | `Edycja: ładowanie`                      | szkielety pól w kształcie formularza, bez przycisków                | E2-P12            |
| Jedna koperta                  | `Edycja wydatku`                         | zapisane wartości, wybrana koperta, „Zapisz zmiany”, „Anuluj”       | US-19             |
| Podział                        | `Edycja: podział`                        | włączony podział, dwie części, „Podzielono całą kwotę.”             | US-19, US-18      |
| Nie istnieje albo brak dostępu | `Edycja: nie istnieje albo brak dostępu` | jeden komunikat, „Wróć do operacji”, bez formularza                 | PT404             |
| Zapisywanie                    | `Edycja: zapisywanie`                    | „Zapisywanie…”, drugie wysłanie nic nie robi                        | wzorzec Formularz |
| Błąd serwera                   | `Edycja: błąd serwera`                   | komunikat nad przyciskami, wpisane dane zostają                     | wzorzec Formularz |
| Sukces                         | `Edycja: sukces`                         | po odpowiedzi serwera szczegóły wydatku z nowymi danymi, bez toastu | US-19, E2-P13     |

Błędy pól, suma części i odpowiedzi API (`ENVELOPE_ARCHIVED`, `SPLITS_INVALID`): wzorzec „Podział wydatku”. „Anuluj” wraca do szczegółów bez zapisu.

## Użyte elementy

- Widoki: `ExpenseForm`, `OperationsPanel`, `ExpenseDetails`.
- Wzorce: podział wydatku, formularz, lista z filtrem miesiąca, widok szczegółów, potwierdzenie usunięcia.
- Komponenty: szkielet ładowania.
