# Ekrany: Koperty

Widok kopert z pulą – pierwszy ekran po otwarciu aplikacji (US-21) – i zarządzanie kopertami (US-11–US-13).

## Widok kopert (`/`)

| Stan         | Story                        | Co widać                                                 | Źródło     |
| ------------ | ---------------------------- | -------------------------------------------------------- | ---------- |
| Z danymi     | `Widok kopert`               | pula z „Przydziel środki”, salda kopert, debet z „Debet” | US-21, K3  |
| Pusty budżet | `Widok kopert: pusty budżet` | pula 0 zł z „Dodaj przychód”, „Dodaj kopertę”            | US-21      |
| Ładowanie    | `Widok kopert: ładowanie`    | szkielety puli i kart                                    | E2-P12     |
| Błąd         | `Widok kopert: błąd`         | komunikaty z „Spróbuj ponownie”                          | WCAG 3.3.1 |

## Zarządzanie kopertami

| Stan         | Story                       | Co widać                                     | Źródło            |
| ------------ | --------------------------- | -------------------------------------------- | ----------------- |
| Kolejność    | `Zarządzanie: kolejność`    | przyciski „Przesuń w górę / w dół”, „Gotowe” | US-12, E3-Q3      |
| Archiwum     | `Zarządzanie: archiwum`     | zarchiwizowane pod aktywnymi, „Przywróć”     | US-13             |
| Nowa koperta | `Zarządzanie: nowa koperta` | formularz nazwy                              | US-11             |
| Nazwa zajęta | `Zarządzanie: nazwa zajęta` | `ENVELOPE_NAME_TAKEN` przy polu              | US-11, US-12 [Z3] |

Lista kopert stoi pod nagłówkiem `h2` „Salda kopert”, bo karty są nagłówkami `h3` (WCAG 1.3.1).
