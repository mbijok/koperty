# Edytor podziału

`import { SplitEditor, type SplitPart } from "@koperty/ui/product/expenses/split-editor";` · podpowiedzi: `import { splitEvenly, remainingToSplit } from "@koperty/ui/lib/split";`

## 1. Do czego służy

Pozwala rozdzielić jeden paragon na kilka kopert i od razu widać, ile jeszcze zostało do podziału.

## 2. Kiedy używać

| Sytuacja w produkcie                                             | Źródło       |
| ---------------------------------------------------------------- | ------------ |
| Formularz wydatku po włączeniu „Podziel wydatek na kilka kopert” | US-18, E3-Q4 |
| Edycja wydatku z podziałem                                       | US-19        |

## 3. Kiedy nie używać

| Sytuacja                              | Zamiast                     | Źródło |
| ------------------------------------- | --------------------------- | ------ |
| Wydatek na jedną kopertę              | select koperty w formularzu | US-17  |
| Przesunięcie środków między kopertami | brak w MVP                  | PRD 3  |

## 4. Anatomia

| Część                             | Opcjonalna | Uwagi                                                                                                             |
| --------------------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------- |
| Grupa „Podział wydatku”           | nie        | `fieldset` z legendą                                                                                              |
| Część N                           | nie        | `fieldset` z nazwą „Część N”: koperta (select) i kwota (pole kwoty); „Usuń część N” od dwóch części               |
| Podsumowanie                      | nie        | „Do podziału: … zł”, „Podzielono całą kwotę.” albo „Części przekraczają kwotę wydatku o … zł”, region `aria-live` |
| „Dodaj część”, „Podziel po równo” | nie        | przyciski `secondary`                                                                                             |

## 10. API

| Prop / funkcja                     | Typ                                          | Opis                                           |
| ---------------------------------- | -------------------------------------------- | ---------------------------------------------- |
| `total`                            | `number \| null`                             | kwota wydatku w groszach (z `parsePLN`)        |
| `parts`                            | `SplitPart[]` (`id`, `envelopeId`, `amount`) | części; `amount` to tekst pola                 |
| `envelopes`                        | `{ id, name }[]`                             | aktywne koperty                                |
| `onPartsChange`                    | `(parts: SplitPart[]) => void`               | zmiana części                                  |
| `errors`                           | `Record<id, { envelope?, amount? }>`         | błędy części                                   |
| `createPartId`                     | `() => string`                               | identyfikator nowej części (domyślnie UUID)    |
| `splitEvenly(total, parts)`        | `[part, grosze][]`                           | równy podział z resztą w pierwszej części      |
| `remainingToSplit(total, amounts)` | `number`                                     | ile zostało (niepoprawne kwoty liczone jako 0) |

## 11. Kod

Typowy w produkcie (formularz wydatku, US-18):

```tsx
<SplitEditor
  total={parsePLN(amount)}
  parts={parts}
  envelopes={activeEnvelopes}
  onPartsChange={setParts}
  errors={partErrors}
/>
```

## 12. Dobrze i źle

| Dobrze                                        | Źle                                                           |
| --------------------------------------------- | ------------------------------------------------------------- |

## 13. Powiązane

- Mylony z: **selectem koperty** (wydatek na jedną kopertę).
- Występuje we wzorcach: podział wydatku, formularz.
