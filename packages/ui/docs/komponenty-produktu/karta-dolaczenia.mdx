# Karta dołączenia

`import { JoinBudgetCard } from "@koperty/ui/product/budgets/join-budget-card";`

## 1. Do czego służy

Po otwarciu linku zaproszenia mówi, do jakiego budżetu i kto zaprasza, i pozwala świadomie dołączyć.

## 2. Kiedy używać

| Sytuacja w produkcie                                                  | Źródło |
| --------------------------------------------------------------------- | ------ |
| Ekran dołączania po otwarciu linku (także po zalogowaniu się z linku) | US-08  |

## 3. Kiedy nie używać

| Sytuacja                 | Zamiast                                                 | Źródło |
| ------------------------ | ------------------------------------------------------- | ------ |
| Osoba jest już członkiem | przekierowanie do budżetu bez karty i bez zużycia linku | US-08  |
| Generowanie linku        | panel linku zaproszenia                                 | US-07  |

## 4. Anatomia

| Część                            | Opcjonalna | Uwagi                                                |
| -------------------------------- | ---------- | ---------------------------------------------------- |
| Tytuł `h1`                       | nie        | „Dołącz do budżetu „Dom””                            |
| Kto zaprasza, co to znaczy       | nie        | dołączysz jako członek                               |
| „Dołącz do budżetu”, „Nie teraz” | nie        | na telefonie jeden pod drugim, akcja główna na górze |

## 5. Warianty

| Stan                         | Wygląd                              |
| ---------------------------- | ----------------------------------- |
| `checking`                   | wskaźnik „Sprawdzanie zaproszenia…” |
| `valid`                      | karta z akcjami                     |
| `expired`, `used`, `revoked` | stan błędu z „Przejdź do aplikacji” |

## 7. Zachowanie i dostępność

| Zasada                                                             | Źródło            |
| ------------------------------------------------------------------ | ----------------- |
| Tytuł to `h1` ekranu dołączania (sprawdza test).                   | WCAG 1.3.1, 2.4.6 |
| Komunikat o nieważnym linku ma `role="alert"`.                     | WCAG 4.1.3        |
| Dołączenie dopiero po kliknięciu – otwarcie linku nic nie zmienia. | US-08             |

## 8. Treść

| Stan         | Tytuł                                                                          | Źródło   |
| ------------ | ------------------------------------------------------------------------------ | -------- |
| Ważne        | „Dołącz do budżetu „Dom””                                                      | US-08    |
| Wygasło      | „Ten link zaproszenia wygasł”                                                  | US-08    |
| Użyte        | „Ten link zaproszenia został już użyty”                                        | US-08    |
| Unieważnione | „Ten link zaproszenia został unieważniony”                                     | US-08    |
| Opis błędu   | „Poproś właściciela budżetu o nowy link. Linki działają raz i są ważne 7 dni.” | PRD 4.10 |

## 9. Responsywność

Na 320 px przyciski jeden pod drugim, „Dołącz do budżetu” na górze; od 768 px obok siebie.

## 10. API

| Prop                      | Typ                                                         | Opis             |
| ------------------------- | ----------------------------------------------------------- | ---------------- |
| `state`                   | `"checking" \| "valid" \| "expired" \| "used" \| "revoked"` | stan linku       |
| `budgetName`, `invitedBy` | `string`                                                    | dane zaproszenia |
| `joining`                 | `boolean`                                                   | trwa dołączanie  |
| `onJoin`, `onGoHome`      | `() => void`                                                | akcje            |

## 11. Kod

```tsx
<JoinBudgetCard
  state={invitation.state}
  budgetName={invitation.budget_name}
  invitedBy={invitation.invited_by}
  joining={join.isPending}
  onJoin={() => join.mutate()}
  onGoHome={() => navigate({ to: "/" })}
/>
```

## 12. Dobrze i źle

| Dobrze                                                          | Źle                                   |
| --------------------------------------------------------------- | ------------------------------------- |
| Nazwa budżetu i zapraszającego przed dołączeniem.               | Dołączenie od razu po otwarciu linku. |

## 13. Powiązane

- Mylona z: **stanem błędu**, **panelem linku zaproszenia**.
- Występuje we wzorcu: udostępnienie i otwarcie zaproszenia.
