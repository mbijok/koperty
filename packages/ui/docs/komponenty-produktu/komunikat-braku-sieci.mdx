# Komunikat braku sieci

`import { OfflineBanner } from "@koperty/ui/product/app/offline-banner";`

## 1. Do czego służy

Informuje, że nie ma połączenia z internetem, i mówi, co to znaczy dla zapisu. Pojawia się i znika sam.

## 2. Kiedy używać

| Sytuacja w produkcie                  | Źródło |
| ------------------------------------- | ------ |
| Raz w układzie ekranów po zalogowaniu | US-23  |

## 3. Kiedy nie używać

| Sytuacja                     | Zamiast              | Źródło            |
| ---------------------------- | -------------------- | ----------------- |
| Nieudany zapis formularza    | komunikat formularza | wzorzec Formularz |
| Kilka komunikatów na ekranie | jeden w układzie     | –                 |

## 4. Anatomia

| Część              | Opcjonalna | Uwagi                           |
| ------------------ | ---------- | ------------------------------- |
| Ikona „brak Wi-Fi” | nie        | dekoracyjna (`aria-hidden`)     |
| Tytuł              | nie        | „Brak połączenia z internetem”  |
| Opis               | nie        | co widać i kiedy zadziała zapis |

## 5. Warianty

Jeden wariant (alert informacyjny); nie jest błędem użytkownika, więc nie ma wariantu `danger`.

## 6. Stany

| Stan              | Story              | Zachowanie          | Źródło |
| ----------------- | ------------------ | ------------------- | ------ |
| Bez połączenia    | `Playground`       | komunikat           | US-23  |
| Z połączeniem     | `ZPolaczeniem`     | nic                 | US-23  |
| Powrót połączenia | `PowrotPolaczenia` | komunikat znika sam | US-23  |

## 7. Zachowanie i dostępność

| Zasada                                                                             | Źródło     |
| ---------------------------------------------------------------------------------- | ---------- |
| Stan z `navigator.onLine` i zdarzeń `online` / `offline` (`useSyncExternalStore`). | US-23      |
| `role="status"`: ogłaszany grzecznie, bez przenoszenia fokusu.                     | WCAG 4.1.3 |

## 8. Treść

| Zasada                          | Przykład                                                                 | Źródło              |
| ------------------------------- | ------------------------------------------------------------------------ | ------------------- |
