# Lista operacji

`import { OperationList } from "@koperty/ui/product/expenses/operation-list";`

## 1. Do czego służy

Pokazuje przychody i wydatki wybranego miesiąca od najnowszych, pogrupowane dniami, żeby łatwo je sprawdzić i poprawić.

## 2. Kiedy używać

| Sytuacja w produkcie                       | Źródło |
| ------------------------------------------ | ------ |
| Ekran „Operacje” z przełącznikiem miesiąca | US-20  |

## 3. Kiedy nie używać

| Sytuacja                      | Zamiast             | Źródło        |
| ----------------------------- | ------------------- | ------------- |
| Porównanie kopert w miesiącu  | tabela podsumowania | US-22, E2-P11 |
| Historia wielu miesięcy naraz | brak w MVP          | PRD 3         |

## 4. Anatomia

| Część                        | Opcjonalna | Uwagi                                                   |
| ---------------------------- | ---------- | ------------------------------------------------------- |
| Sekcja dnia                  | nie        | nagłówek `h3` „czwartek, 29 października”, lista `<ul>` |
| Wiersz operacji              | nie        | `OperationRow`                                          |
| Stan ładowania, pusty, błędu | –          | zamiast listy                                           |

## 5. Warianty

Jeden wariant. Kolejność operacji pochodzi z API (od najnowszych); lista tylko grupuje kolejne operacje z tą samą datą.

## 10. API

| Prop                          | Typ                          | Opis                             |
| ----------------------------- | ---------------------------- | -------------------------------- |
| `operations`                  | `Operation[]`                | operacje miesiąca od najnowszych |
| `month`                       | `string`                     | `RRRR-MM`                        |
| `budgetHasOperations`         | `boolean` (domyślnie `true`) | wybiera pusty stan               |
| `loading`, `error`, `onRetry` | –                            | stany wczytywania                |
| `onCreate`                    | `() => void`                 | akcja pustego budżetu            |
| `onPreviousMonth`             | `() => void`                 | akcja pustego miesiąca           |
| `onEdit`, `onDelete`          | `(id: string) => void`       | akcje wierszy                    |

## 11. Kod

Typowy w produkcie (ekran Operacje, US-20):

```tsx
<OperationList
  month={month}
  operations={operations.data}
  budgetHasOperations={budget.data?.hasOperations}
  loading={operations.isPending}
  error={operations.isError ? "Nie udało się wczytać operacji" : undefined}
  onRetry={() => operations.refetch()}
  onPreviousMonth={() => navigate({ search: { month: addMonths(month, -1) } })}
  onCreate={() => navigate({ to: "/expenses/new" })}
  onEdit={openEdit}
  onDelete={confirmDelete}
/>
```
