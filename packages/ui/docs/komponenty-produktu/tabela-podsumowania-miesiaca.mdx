# Tabela podsumowania miesiąca

`import { MonthSummaryTable } from "@koperty/ui/product/overview/month-summary-table";`

## 1. Do czego służy

Pokazuje dla każdej koperty, z czym zaczęła miesiąc, ile dostała, ile wydano i ile zostało, oraz przychody i pulę.

## 2. Kiedy używać

| Sytuacja w produkcie                    | Źródło |
| --------------------------------------- | ------ |
| Ekran „Podsumowanie” wybranego miesiąca | US-22  |

## 3. Kiedy nie używać

| Sytuacja       | Zamiast        | Źródło |
| -------------- | -------------- | ------ |
| Bieżące salda  | lista kopert   | US-21  |
| Lista operacji | lista operacji | US-20  |
| Wykresy        | brak w MVP     | PRD 3  |

## 4. Anatomia

| Część          | Opcjonalna | Uwagi                                                                        |
| -------------- | ---------- | ---------------------------------------------------------------------------- |
| Sumy miesiąca  | tak        | „Przychody w miesiącu”, „Przydziały w miesiącu”, „Do rozdysponowania” (`dl`) |
| Tabela         | nie        | `Table` z nazwą „Podsumowanie: Październik 2026”, kolumny kwot do prawej     |
| Wiersze kopert | nie        | tylko koperty używane w miesiącu, nazwa jako nagłówek wiersza                |

## 5. Warianty

Jeden wariant. Kwoty wylicza baza (saldo początkowe + przydział − wydatki = saldo końcowe); komponent ich nie przelicza.

## 10. API

| Prop                          | Typ                                                                        | Opis                               |
| ----------------------------- | -------------------------------------------------------------------------- | ---------------------------------- |
| `month`                       | `string`                                                                   | `RRRR-MM`                          |
| `rows`                        | `EnvelopeMonth[]` (`id`, `name`, `start`, `allocation`, `expenses`, `end`) | koperty używane w miesiącu, grosze |
| `totals`                      | `{ incomes, allocations, pool }`                                           | sumy miesiąca, grosze              |
| `loading`, `error`, `onRetry` | –                                                                          | stany wczytywania                  |

## 11. Kod

Typowy w produkcie (ekran Podsumowanie, US-22):

```tsx
<MonthSwitcher month={month} onMonthChange={setMonth} />
<MonthSummaryTable month={month} rows={summary.data?.envelopes} totals={summary.data?.totals} loading={summary.isPending} />
```

## 13. Powiązane

- Mylona z: **tabelą** (komponent bazowy), **listą kopert**.
- Występuje we wzorcach: nawigacja po miesiącach, kwota ujemna i debet.
