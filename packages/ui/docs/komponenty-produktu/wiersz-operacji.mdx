# Wiersz operacji

`import { OperationRow, type Operation } from "@koperty/ui/product/expenses/operation-row";`

## 1. Do czego służy

Pokazuje jeden przychód lub wydatek: ile, na co, z których kopert i kto go zapisał.

## 2. Kiedy używać

| Sytuacja w produkcie                                 | Źródło       |
| ---------------------------------------------------- | ------------ |
| Wiersz na liście operacji miesiąca                   | US-20        |
| Wejście do edycji i usuwania operacji (także cudzej) | US-15, US-19 |

## 3. Kiedy nie używać

| Sytuacja                                | Zamiast                            | Źródło |
| --------------------------------------- | ---------------------------------- | ------ |
| Pełne dane wydatku z częściami podziału | widok szczegółów wydatku (wzorzec) | US-19  |
| Saldo koperty                           | karta koperty                      | US-21  |

## 4. Anatomia

| Część            | Opcjonalna | Uwagi                                                               |
| ---------------- | ---------- | ------------------------------------------------------------------- |
| Awatar autora    | nie        | inicjały, dekoracyjny                                               |
| Opis             | nie        | opis albo „Wydatek bez opisu” / „Przychód bez opisu” w `text-muted` |
| Metadane         | nie        | koperta albo „Podział: Jedzenie, Chemia” · autor                    |
| Kwota            | nie        | przychód z „+”, wydatek bez znaku (P7)                              |
| „Edytuj”, „Usuń” | tak        | przyciski ikonowe 32 px z podpowiedzią (dwie akcje widoczne, E2-P9) |

## 5. Warianty

| Rodzaj   | Różnica                                           |
| -------- | ------------------------------------------------- |
| Wydatek  | koperta lub podział w metadanych, kwota bez znaku |
| Przychód | bez kopert, kwota z „+”                           |

## 7. Zachowanie i dostępność

| Zasada                                                                             | Źródło                  |
| ---------------------------------------------------------------------------------- | ----------------------- |

| „Usuń” nie usuwa od razu – ekran otwiera dialog potwierdzenia.                     | US-19, polecenie budowy |

## 9. Responsywność

Na 320 px opis i metadane się zawijają, kwota i akcje zostają w wierszu; na 768 i 1440 px wiersz w `max-w-content`.

## 10. API

| Prop                 | Typ                     | Opis                                      |
| -------------------- | ----------------------- | ----------------------------------------- |
| `type`               | `"income" \| "expense"` | rodzaj                                    |
| `amount`             | `number`                | grosze, dodatnie                          |
| `date`               | `string`                | `RRRR-MM-DD` (nagłówek dnia rysuje lista) |
| `description`        | `string`                | opcjonalny opis                           |
| `envelopes`          | `string[]`              | nazwy kopert części                       |
| `author`             | `string`                | nazwa autora                              |
| `onEdit`, `onDelete` | `() => void`            | akcje                                     |

## 11. Kod

Typowy w produkcie (najczęściej przez `OperationList`):

```tsx
<OperationRow
  {...operation}
  onEdit={() => openEdit(operation.id)}
  onDelete={() => confirmDelete(operation)}
/>
```

## 12. Dobrze i źle

| Dobrze                                                  | Źle                      |
| ------------------------------------------------------- | ------------------------ |

## 13. Powiązane

- Mylony z: **kartą koperty**, **widokiem szczegółów wydatku**.
- Występuje we wzorcach: lista z filtrem miesiąca, potwierdzenie usunięcia.
