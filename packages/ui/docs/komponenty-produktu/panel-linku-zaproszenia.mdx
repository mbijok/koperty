# Panel linku zaproszenia

`import { InviteLinkPanel } from "@koperty/ui/product/budgets/invite-link-panel";`

## 1. Do czego służy

Pozwala właścicielowi wygenerować jednorazowy link i przekazać go dowolnym komunikatorem.

## 2. Kiedy używać

| Sytuacja w produkcie                     | Źródło          |
| ---------------------------------------- | --------------- |
| Ustawienia budżetu, sekcja „Zaproszenia” | US-07, PRD 4.10 |

## 3. Kiedy nie używać

| Sytuacja                        | Zamiast           | Źródło |
| ------------------------------- | ----------------- | ------ |
| Zaproszenie na konkretny e-mail | brak w MVP        | PRD 3  |
| Lista wcześniejszych linków     | wiersze zaproszeń | US-07  |

## 4. Anatomia

| Część                       | Opcjonalna              | Uwagi                                                                       |
| --------------------------- | ----------------------- | --------------------------------------------------------------------------- |
| Karta „Zaproś osobę”        | nie                     | nagłówek `h2`, wyjaśnienie: link działa raz, 7 dni                          |
| „Wygeneruj link”            | do wygenerowania        | przycisk z ładowaniem „Generowanie…”                                        |
| Pole „Link zaproszenia”     | po wygenerowaniu        | tylko do odczytu, krój o stałej szerokości (P8), podpowiedź z datą ważności |
| „Kopiuj link”, „Udostępnij” | „Udostępnij” opcjonalne | „Udostępnij” tylko tam, gdzie działa systemowe udostępnianie                |

## 7. Zachowanie i dostępność

| Zasada                                                                             | Źródło     |
| ---------------------------------------------------------------------------------- | ---------- |
| Pole ma etykietę i podpowiedź z datą ważności (sprawdza test).                     | WCAG 1.3.1 |
| Kopiowanie potwierdza toast – informacja nie jest potrzebna do dalszego działania. | E2-Q4      |
| „Udostępnij” pokazujesz tylko, gdy przeglądarka ma `navigator.share`.              | WCAG 3.2.4 |

## 8. Treść

| Element         | Tekst                                                                     | Źródło   |
| --------------- | ------------------------------------------------------------------------- | -------- |
| Opis            | „Wyślij link dowolnym komunikatorem. Link działa raz i jest ważny 7 dni.” | PRD 4.10 |
| Podpowiedź pola | „Ważny do 5 listopada 2026. Działa raz.”                                  | PRD 4.10 |

## 9. Responsywność

Na 320 px przyciski jeden pod drugim (zawijanie stopki karty), link przewija się w polu; na 768 i 1440 px obok siebie.

## 10. API

| Prop                   | Typ          | Opis                                 |
| ---------------------- | ------------ | ------------------------------------ |
| `link`                 | `string`     | wygenerowany link                    |
| `expiresOn`            | `string`     | `RRRR-MM-DD`                         |
| `generating`           | `boolean`    | trwa generowanie                     |
| `error`                | `string`     | błąd generowania                     |
| `onGenerate`, `onCopy` | `() => void` | akcje                                |
| `onShare`              | `() => void` | systemowe udostępnianie (opcjonalne) |

## 11. Kod

```tsx
<InviteLinkPanel
  link={invitation.data?.url}
  expiresOn={invitation.data?.expires_on}
  generating={createInvitation.isPending}
  onGenerate={() => createInvitation.mutate()}
  onCopy={async () => {
    await navigator.clipboard.writeText(url);
    showToast("Link skopiowany");
  }}
  onShare={"share" in navigator ? () => navigator.share({ url }) : undefined}
/>
```
