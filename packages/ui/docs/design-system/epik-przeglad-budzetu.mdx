# Epik: Przegląd budżetu

Podsumowanie wybranego miesiąca: salda kopert na początek i koniec, przydziały, wydatki, przychody i pula (US-22).

## Kroki przepływu

1. Członek otwiera „Podsumowanie”; widzi bieżący miesiąc.
2. Przełącza miesiące, także przyszłe (zaplanowane przydziały).
3. Saldo końcowe miesiąca jest saldem początkowym następnego; debet jest oznaczony.

## Ekrany i stories

**Widoki wstępne:** ekrany tego epiku powstały przed specyfikacjami zadań z backlogu. Specyfikacja zadania może je zmienić; różnice trafiają na stronę „Czego brakuje”, a widok w pakiecie poprawia zadanie, które go podpina.
