# Epik: Przychody i przydziały

Przychody zwiększają pulę, przydziały przenoszą środki z puli do kopert w danym miesiącu (US-14–US-16).

## Kroki przepływu

1. Członek zapisuje przychód (kwota, data, opis); pula rośnie.
2. Poprawia lub usuwa przychód (z potwierdzeniem).
3. Przydziela środki kopercie na miesiąc, także przyszły; widzi pulę po zapisie, także ujemną.
4. Zmniejszenie przydziału zwraca różnicę do puli; debet koperty pokrywa się zwiększeniem przydziału.
