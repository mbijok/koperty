# Epik: Budżety i członkostwo

Utworzenie i przełączanie budżetów, zaproszenia, członkowie i role, zmiana nazwy i usunięcie budżetu (US-04–US-10).

## Kroki przepływu

1. Po pierwszym logowaniu osoba bez budżetu tworzy pierwszy budżet i zostaje właścicielem.
2. Przełącza budżety w nagłówku; kolejne tworzy z przełącznika.
3. Właściciel generuje link zaproszenia (7 dni, jednorazowy) i przekazuje go dowolnym kanałem; może go unieważnić.
4. Zaproszona osoba otwiera link, w razie potrzeby loguje się i dołącza jako członek.
5. Właściciel zarządza rolami, usuwa członków, zmienia nazwę lub usuwa budżet; członek może opuścić budżet (nie ostatni właściciel).
