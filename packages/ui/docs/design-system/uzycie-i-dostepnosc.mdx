# Użycie i dostępność

Cel: WCAG 2.1 AA (DS-S01, PRD 6). Każda reguła ma źródło; reguła bez źródła jest oznaczona jako propozycja. Stories sprawdzają axe w obu motywach (`vp run test:storybook`), naruszenie jest błędem testu.

## Klawiatura i fokus

| Zasada                                                                                                 | Źródło                        |
| ------------------------------------------------------------------------------------------------------ | ----------------------------- |
| Wszystko działa z klawiatury; kolejność fokusu zgodna z kolejnością na ekranie.                        | WCAG 2.1.1, 2.4.3             |
| Fokus widoczny: pełna linia 2 px w kolorze `focus-ring`, odstęp 2 px, kontrast ≥ 3 : 1.                | K2, W2, WCAG 2.4.7, 1.4.11    |
| Pierwszy Tab na ekranie po zalogowaniu trafia w „Przejdź do treści”.                                   | WCAG 2.4.1, powłoka aplikacji |
| Dialog: fokus w środku, Escape zamyka, po zamknięciu fokus wraca na element, który go otworzył.        | WAI-ARIA APG (dialog)         |
| Dialog potwierdzenia: fokus startowy na „Anuluj”.                                                      | WAI-ARIA APG (alertdialog)    |
| Po zmianie kroku formularza fokus trafia na pole nowego kroku; po błędzie – na pierwsze pole z błędem. | WCAG 2.4.3, 3.3.1             |
| Zmiana kolejności kopert przyciskami, fokus zostaje na przesuniętej kopercie; bez przeciągania.        | E3-Q3, WCAG 2.5.7             |
| Przewijana tabela ma nazwę i `tabIndex=0`, przewija się strzałkami.                                    | WCAG 2.1.1, axe               |

## Formularze i komunikaty

| Zasada                                                                                            | Źródło            |
| ------------------------------------------------------------------------------------------------- | ----------------- |
| Etykieta zawsze widoczna (`FormField`), nigdy tylko placeholder.                                  | WCAG 3.3.2, 1.3.1 |
| Błąd przy polu, połączony `aria-describedby`, pole ma `aria-invalid`.                             | WCAG 3.3.1        |
| Walidacja po opuszczeniu pola i przy wysłaniu, nie w trakcie pisania.                             | polecenie budowy  |
| Dane zostają po każdym błędzie; sukces dopiero po potwierdzeniu z serwera.                        | polecenie budowy  |
| Komunikat błędu mówi, co zrobić, z przykładem.                                                    | WCAG 3.3.3        |
| Pola mają `autocomplete` i klawiaturę dopasowaną do treści (`email`, `one-time-code`, `decimal`). | WCAG 1.3.5        |
| Tekst w polach 16 px – iOS Safari nie powiększa strony przy fokusie.                              | K1                |
| Zmiany stanu ogłaszane bez przenoszenia fokusu: licznik wyników, miesiąc, brak sieci.             | WCAG 4.1.3        |

## Reguły produktu pilnowane przez interfejs

Reguły domenowe egzekwuje baza (AGENTS.md, ADR 0003). Interfejs tylko je pokazuje i pomaga ich przestrzegać:

| Reguła                                                    | Co robi interfejs                                                    | Źródło                   |
| --------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------ |
| Saldo koperty i pula mogą być ujemne                      | minus i „Debet”, bez blokady zapisu; podgląd puli przed przydziałem  | PRD 4.3, 4.5, US-16      |
| Suma części wydatku równa kwocie                          | „Do podziału”, „Podziel po równo” (reszta groszy w pierwszej części) | PRD 4.6, US-18           |
| Archiwizacja tylko przy saldzie zero                      | pozycja menu zablokowana z wyjaśnieniem                              | US-13 [Z4]               |
| Ostatni właściciel nie opuszcza budżetu                   | „Opuść budżet…” zablokowane z wyjaśnieniem                           | PRD 4.9, US-10           |
| Archiwalnych kopert nie ma w wyborze wydatku i przydziału | select pokazuje tylko aktywne koperty                                | US-13                    |
| Obiekt innego budżetu jest „nie istnieje”                 | jeden komunikat „nie istnieje albo brak dostępu”                     | kontrakt błędów (PT404)  |
| Kwoty w groszach, daty bez godzin                         | `parsePLN`, `formatPLN`, `todayInWarsaw` z `@koperty/ui/lib`         | AGENTS.md, standardy 4.4 |
