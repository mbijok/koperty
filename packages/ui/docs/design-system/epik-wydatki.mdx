# Epik: Wydatki

Szybki zapis wydatku na telefonie, podział na koperty, lista operacji miesiąca, szczegóły, edycja i usunięcie (US-17–US-20).

## Kroki przepływu

1. Członek otwiera „Dodaj wydatek” (dolny pasek na telefonie), wpisuje kwotę, wybiera kopertę, zapisuje.
2. Jeśli paragon dotyczy kilku kopert, włącza podział; suma części równa się kwocie.
3. Na liście operacji wybiera miesiąc; widzi licznik i dni z operacjami.
4. Otwiera szczegóły wydatku, edytuje go albo usuwa z potwierdzeniem.

## Ekrany i stories

**Widoki wstępne:** ekrany tego epiku powstały przed specyfikacjami zadań z backlogu. Specyfikacja zadania może je zmienić; różnice trafiają na stronę „Czego brakuje”, a widok w pakiecie poprawia zadanie, które go podpina.

## Praca, która zostaje w produkcie

Design system daje interfejs ze stanami; każde zadanie dostarcza resztę jako vertical slice (migracja, RLS, RPC, testy pgTAP, trasa, zapytania TanStack Query, podpięcie widoku) według zatwierdzonej specyfikacji. Nazwy funkcji z `docs/architecture.md`.
