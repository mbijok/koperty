# Epik: Koperty

Widok kopert z pulą po otwarciu aplikacji, dodawanie, nazwy, kolejność i archiwizacja kopert (US-11–US-13, US-21).

## Kroki przepływu

1. Po otwarciu aplikacji osoba widzi pulę „Do rozdysponowania” i salda kopert; debet jest oznaczony.
2. Nowy budżet zachęca do pierwszej koperty i przychodu.
3. Członek dodaje kopertę, zmienia jej nazwę i kolejność (przyciski w górę / w dół).
4. Kopertę z saldem zero archiwizuje; zarchiwizowaną może przywrócić.

## Ekrany i stories

**Widoki wstępne:** ekrany tego epiku powstały przed specyfikacjami zadań z backlogu. Specyfikacja zadania może je zmienić; różnice trafiają na stronę „Czego brakuje”, a widok w pakiecie poprawia zadanie, które go podpina.
