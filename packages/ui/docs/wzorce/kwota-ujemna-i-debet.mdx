# Kwota ujemna i debet

`import { AllocationForm } from "@koperty/ui/views/funds/allocation-form";`

## 1. Do czego służy

Pokazuje ujemne salda i ujemną pulę tak samo w całym produkcie oraz prowadzi do wyjścia z debetu: zwiększenia przydziału. Formularz przydziału pokazuje pulę po zapisie, zanim osoba zapisze.

## 2. Kiedy używać

| Sytuacja w produkcie                          | Źródło         |
| --------------------------------------------- | -------------- |
| Przydział środków do koperty (także przyszły) | US-16          |
| Saldo koperty poniżej zera po wydatku         | US-17, PRD 4.5 |
| Pula poniżej zera                             | US-16, PRD 4.3 |

## 3. Kiedy nie używać

| Sytuacja                       | Zamiast                             | Źródło       |
| ------------------------------ | ----------------------------------- | ------------ |
| Kwota wydatku w liście         | kwota `kind="expense"` (bez minusa) | P7           |
| Blokowanie zapisu przy debecie | nigdy – debet jest dozwolony        | PRD 4.3, 4.5 |

## 4. Anatomia

| Część               | Opcjonalna | Uwagi                              |
| ------------------- | ---------- | ---------------------------------- |
| Kwota z minusem „−” | nie        | `Amount`, znak minus, nie łącznik  |
| Znacznik „Debet”    | nie        | przy saldzie i puli poniżej zera   |
| Pole przydziału     | nie        | etykieta z kopertą i miesiącem     |
| „Pula po zapisie”   | nie        | podgląd na żywo, `aria-live`       |
| Wyjaśnienie         | tak        | przy puli ujemnej: zapis dozwolony |

## 5. Warianty

Formularz: nowy przydział (puste pole) i zmiana istniejącego (kwota w polu, zmniejszenie zwraca różnicę do puli).

## 7. Zachowanie i dostępność

| Zasada                                                                    | Źródło             |
| ------------------------------------------------------------------------- | ------------------ |
| Ujemna wartość ma minus i słowo „Debet”, nigdy sam kolor.                 | K3, W4, WCAG 1.4.1 |
| Debet nie blokuje zapisu; interfejs mówi, co się stanie.                  | PRD 4.3, 4.5       |
| Podgląd puli liczy klient tylko dla wygody; pulę wylicza baza z historii. | PRD 4.3, AGENTS.md |
| Zero usuwa przydział (zwraca całość do puli).                             | propozycja (E3-P9) |
| Wyjście z debetu: „Przydziel środki” przy kopercie.                       | PRD 4.5            |

## 10. API

| Prop                    | Typ                                                   | Opis                                   |
| ----------------------- | ----------------------------------------------------- | -------------------------------------- |
| `envelopeName`          | `string`                                              | koperta                                |
| `month`                 | `string`                                              | `RRRR-MM`                              |
| `current`               | `number`                                              | obecny przydział w groszach (0 = brak) |
| `pool`                  | `number`                                              | pula przed zmianą                      |
| `submit`                | `(amount: number) => Promise<SubmitResult<"amount">>` | `set_allocation`                       |
| `onSuccess`, `onCancel` | –                                                     | jak w formularzu                       |

## 11. Kod

```tsx
<AllocationForm
  envelopeName={envelope.name}
  month={month}
  current={allocation.data?.amount ?? 0}
  pool={pool.data ?? 0}
  submit={async (amount) => {
    const { error } = await supabase.rpc("set_allocation", {
      p_envelope_id: envelope.id,
      p_period: `${month}-01`,
      p_amount: amount,
    });
    if (error) throw error;
    return { ok: true };
  }}
  onSuccess={() => navigate({ to: "/" })}
/>
```
