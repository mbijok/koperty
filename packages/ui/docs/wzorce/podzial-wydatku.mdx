# Podział wydatku

`import { ExpenseForm } from "@koperty/ui/views/expenses/expense-form";`

## 1. Do czego służy

Zapisuje wydatek szybko na telefonie: kwota, koperta, data i opcjonalny opis. Jeden paragon można podzielić na kilka kopert.

## 2. Kiedy używać

| Sytuacja w produkcie          | Źródło       |
| ----------------------------- | ------------ |
| Nowy wydatek (osobna strona)  | US-17, E3-Q4 |
| Wydatek z podziałem           | US-18        |
| Edycja wydatku, także cudzego | US-19        |

## 3. Kiedy nie używać

| Sytuacja                | Zamiast              | Źródło |
| ----------------------- | -------------------- | ------ |
| Przychód                | formularz przychodu  | US-14  |
| Przesunięcie do koperty | formularz przydziału | US-16  |

## 4. Anatomia

| Część                             | Opcjonalna | Uwagi                                                          |
| --------------------------------- | ---------- | -------------------------------------------------------------- |
| Kwota                             | nie        | pierwsza, z fokusem przy otwarciu ekranu (`focusAmountOnOpen`) |
| Koperta                           | nie        | select aktywnych kopert; znika przy podziale                   |
| „Podziel wydatek na kilka kopert” | nie        | przełącznik; włączony pokazuje edytor podziału                 |
| Edytor podziału                   | tak        | części, „Do podziału”, „Podziel po równo”                      |
| Data                              | nie        | domyślnie dziś (`Europe/Warsaw`)                               |
| Opis                              | tak        | „opcjonalne”                                                   |

## 5. Warianty

Nowy wydatek i edycja (`initial`, `submitLabel="Zapisz zmiany"`, „Anuluj”). Edycja wydatku z kilkoma częściami otwiera się z włączonym podziałem.

## 7. Zachowanie i dostępność

| Zasada                                                                                             | Źródło             |
| -------------------------------------------------------------------------------------------------- | ------------------ |

| Fokus na kwocie tylko przy otwarciu ekranu, nie w dokumentacji z wieloma przykładami.              | E3-Q4              |
| Tylko aktywne koperty na liście.                                                                   | US-13              |

### Edycja wydatku z częścią na zarchiwizowanej kopercie

`update_expense` pozwala zostawić istniejącą część na kopercie zarchiwizowanej po zapisaniu wydatku (do nowych części tylko aktywne koperty, `docs/architecture.md`), ale `ExpenseForm` dostaje listę `envelopes` i select nie pokaże koperty spoza niej. Sposób prezentacji czeka na decyzję – strona „Czego brakuje”.

## 10. API

| Prop                                   | Typ                                                   | Opis                               |
| -------------------------------------- | ----------------------------------------------------- | ---------------------------------- |
| `envelopes`                            | `{ id: string; name: string }[]`                      | aktywne koperty                    |
| `initial`                              | `{ amount?, date?, description?, parts? }`            | edycja                             |
| `submit`                               | `(values: ExpenseValues) => Promise<SubmitResult<…>>` | `parts` zawsze co najmniej jedna   |
| `onSuccess`, `onCancel`, `submitLabel` | –                                                     | jak w formularzu                   |
| `focusAmountOnOpen`                    | `boolean` (domyślnie `false`)                         | fokus na kwocie po otwarciu ekranu |
| `createPartId`                         | `() => string`                                        | identyfikatory części (testy)      |

Błędy części mają klucze `<id części>.envelope` i `<id części>.amount`.

## 11. Kod

```tsx
<ExpenseForm
  envelopes={envelopes.data ?? []}
  focusAmountOnOpen
  submit={async ({ amount, date, description, parts }) => {
    const { error } = await supabase.rpc("create_expense", {
      p_budget_id: budgetId,
      p_amount: amount,
      p_occurred_on: date,
      p_description: description,
      p_splits: parts.map((part) => ({ envelope_id: part.envelopeId, amount: part.amount })),
    });
    if (!error) return { ok: true };
    if (error.message === "ENVELOPE_ARCHIVED")
      return {
        ok: false,
        fieldErrors: { envelope: "Ta koperta została zarchiwizowana. Wybierz inną." },
      };
    throw error;
  }}
  onSuccess={() => navigate({ to: "/" })}
/>
```

Edycja (US-19): dane z API zamień na `initial` – identyfikatory kopert i kwoty jako tekst (`formatAmountInput`); formularz wyświetl dopiero z danymi:

```tsx
import { formatAmountInput } from "@koperty/ui/lib/money";
import type { ExpenseFormProps } from "@koperty/ui/views/expenses/expense-form";

const expense = useQuery(expenseQuery(expenseId)); // null przy PT404
if (expense.isPending) return <EditExpenseSkeleton />; // szkielet pól, wzorzec Formularz
if (!expense.data) return <ExpenseDetails onBack={() => navigate({ to: "/operations" })} />;

const initial: ExpenseFormProps["initial"] = {
  amount: formatAmountInput(expense.data.amount),
  date: expense.data.occurred_on,
  description: expense.data.description ?? "",
  parts: expense.data.splits.map((split) => ({
    envelopeId: split.envelope_id,
    amount: formatAmountInput(split.amount),
  })),
};

<ExpenseForm
  envelopes={envelopes.data ?? []}
  initial={initial}
  submitLabel="Zapisz zmiany"
  submit={async ({ amount, date, description, parts }) => {
    const { error } = await supabase.rpc("update_expense", {
      p_expense_id: expenseId,
      p_amount: amount,
      p_occurred_on: date,
      p_description: description,
      p_splits: parts.map((part) => ({ envelope_id: part.envelopeId, amount: part.amount })),
    });
    if (error) throw error;
    return { ok: true };
  }}
  onSuccess={() => navigate({ to: "/expenses/$id", params: { id: expenseId } })}
  onCancel={() => navigate({ to: "/expenses/$id", params: { id: expenseId } })}
/>;
```

Ekran: Ekrany → Wydatki, „Edycja wydatku”.
