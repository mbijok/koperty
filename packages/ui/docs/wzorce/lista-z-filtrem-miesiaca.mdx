# Lista z filtrem miesiąca

`import { OperationsPanel } from "@koperty/ui/views/expenses/operations-panel";`

## 1. Do czego służy

Pokazuje operacje wybranego miesiąca z licznikiem wyników i widocznym filtrem. Filtrem w MVP jest miesiąc (Q5); innych filtrów nie ma.

## 2. Kiedy używać

| Sytuacja w produkcie | Źródło    |
| -------------------- | --------- |
| Ekran „Operacje”     | US-20, Q5 |

## 3. Kiedy nie używać

| Sytuacja                            | Zamiast                             | Źródło    |
| ----------------------------------- | ----------------------------------- | --------- |
| Porównanie kopert w miesiącu        | tabela podsumowania                 | US-22     |
| Filtry po kopercie, autorze, kwocie | brak w MVP (strona „Czego brakuje”) | Q5, PRD 3 |

## 4. Anatomia

| Część                        | Opcjonalna | Uwagi                                                 |
| ---------------------------- | ---------- | ----------------------------------------------------- |
| Przełącznik miesiąca         | nie        | aktywny filtr zawsze widoczny                         |
| Licznik „Liczba operacji: N” | nie        | `aria-live="polite"`; ukryty przy ładowaniu i błędzie |
| „Wróć do bieżącego miesiąca” | tak        | tylko gdy wybrany jest inny miesiąc                   |
| Lista operacji               | nie        | `OperationList` ze wszystkimi stanami                 |

Jeden wariant.

## 7. Zachowanie i dostępność

| Zasada                                                                                              | Źródło            |
| --------------------------------------------------------------------------------------------------- | ----------------- |
| Sekcja ma ukryty nagłówek `h2` „Operacje: Październik 2026”, bo dni listy są `h3`; ekran daje `h1`. | WCAG 1.3.1, 2.4.6 |
| Zmiana miesiąca ogłasza nową liczbę wyników bez przenoszenia fokusu.                                | WCAG 4.1.3        |
| Licznik nie pokazuje wartości, której nie znamy (ładowanie, błąd).                                  | polecenie budowy  |
| Dwa puste stany: „brak wyników dla filtra” (zmień filtr) i „jeszcze nic tu nie ma” (dodaj).         | polecenie budowy  |
| Miesiąc trzymaj w adresie (`?month=2026-10`), żeby filtr przetrwał odświeżenie.                     | standardy 4.3     |

## 10. API

| Prop            | Typ                       | Opis                                          |
| --------------- | ------------------------- | --------------------------------------------- |
| `month`         | `string`                  | wybrany miesiąc `RRRR-MM`                     |
| `currentMonth`  | `string`                  | bieżący miesiąc (`monthOf(todayInWarsaw())`)  |
| `onMonthChange` | `(month: string) => void` | zmiana filtra                                 |
| pozostałe       | `OperationListProps`      | jak w liście operacji (bez `onPreviousMonth`) |

## 11. Kod

```tsx
const { month = monthOf(todayInWarsaw()) } = Route.useSearch();
<OperationsPanel
  month={month}
  currentMonth={monthOf(todayInWarsaw())}
  onMonthChange={(next) => navigate({ search: { month: next } })}
  operations={operations.data}
  loading={operations.isPending}
  error={operations.isError ? "Nie udało się wczytać operacji" : undefined}
  onRetry={() => operations.refetch()}
/>;
```
