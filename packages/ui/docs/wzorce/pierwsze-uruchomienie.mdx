# Pierwsze uruchomienie

`import { CreateBudgetForm } from "@koperty/ui/views/budgets/create-budget-form";`

## 1. Do czego służy

Prowadzi nową osobę od pustego konta do pierwszego budżetu, a potem do dwóch pierwszych kroków: koperty i przychodu.

## 2. Kiedy używać

| Sytuacja w produkcie                   | Źródło       |
| -------------------------------------- | ------------ |
| Po pierwszym zalogowaniu, bez budżetów | US-04        |
| „Utwórz budżet” z przełącznika budżetu | US-04, US-05 |
| Nowy budżet bez kopert                 | US-21        |

## 3. Kiedy nie używać

| Sytuacja                      | Zamiast                        | Źródło |
| ----------------------------- | ------------------------------ | ------ |
| Dołączenie do cudzego budżetu | zaproszenie (karta dołączenia) | US-08  |
| Zmiana nazwy budżetu          | ustawienia budżetu (ekrany)    | US-06  |

## 4. Anatomia

| Część                | Opcjonalna | Uwagi                                                         |
| -------------------- | ---------- | ------------------------------------------------------------- |
| Pole „Nazwa budżetu” | nie        | podpowiedź: kto zobaczy nazwę                                 |
| „Utwórz budżet”      | nie        | przycisk główny                                               |
| „Anuluj”             | tak        | tylko gdy osoba ma już inny budżet                            |
| Pusty budżet         | –          | pula 0 zł z „Dodaj przychód” i lista kopert z „Dodaj kopertę” |

## 5. Warianty

Pierwszy budżet (bez „Anuluj”) i kolejny budżet (`KolejnyBudzet`, z „Anuluj”).

## 10. API

| Prop        | Typ                                               | Opis                 |
| ----------- | ------------------------------------------------- | -------------------- |
| `submit`    | `(name: string) => Promise<SubmitResult<"name">>` | `create_budget`      |
| `onSuccess` | `() => void`                                      | przejście do budżetu |
| `onCancel`  | `() => void`                                      | kolejny budżet       |

## 11. Kod

```tsx
<CreateBudgetForm
  submit={async (name) => {
    const { error } = await supabase.rpc("create_budget", { p_name: name });
    if (!error) return { ok: true };
    if (error.message === "BUDGET_NAME_INVALID")
      return { ok: false, fieldErrors: { name: "Podaj inną nazwę." } };
    throw error;
  }}
  onSuccess={() => navigate({ to: "/" })}
/>
```
