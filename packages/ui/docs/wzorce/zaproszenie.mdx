# Zaproszenie

`import { InviteLinkPanel } from "@koperty/ui/product/budgets/invite-link-panel";`

## 1. Do czego służy

Prowadzi przez obie strony zaproszenia: właściciel tworzy jednorazowy link i przekazuje go dowolnym kanałem, a zaproszona osoba otwiera go, w razie potrzeby loguje się i dołącza.

## 2. Kiedy używać

| Sytuacja w produkcie               | Źródło          |
| ---------------------------------- | --------------- |
| Ustawienia budżetu: zaproszenia    | US-07, PRD 4.10 |
| Ekran dołączenia (`/join/<token>`) | US-08           |

## 3. Kiedy nie używać

| Sytuacja                         | Zamiast                                 | Źródło   |
| -------------------------------- | --------------------------------------- | -------- |
| Zmiana roli członka              | wiersz członka                          | US-09    |
| Zaproszenie e-mailem z aplikacji | brak w MVP – link przekazuje właściciel | PRD 4.10 |

## 4. Anatomia

| Część                       | Opcjonalna | Uwagi                                                        |
| --------------------------- | ---------- | ------------------------------------------------------------ |
| Panel linku                 | nie        | „Wygeneruj link”, potem link, „Kopiuj link”, „Udostępnij”    |
| Aktywne zaproszenia         | nie        | wiersze z ważnością i autorem; „Unieważnij…” dla właściciela |
| Potwierdzenie unieważnienia | –          | wzorzec potwierdzenia usunięcia                              |
| Karta dołączenia            | –          | strona zaproszonej osoby                                     |
| Logowanie z komunikatem     | –          | zaproszona osoba bez sesji                                   |

## 5. Warianty

Widok właściciela (tworzy i unieważnia) i widok członka (tylko widzi aktywne zaproszenia).

## 7. Zachowanie i dostępność

| Zasada                                                                     | Źródło                          |
| -------------------------------------------------------------------------- | ------------------------------- |
| Link ważny 7 dni, jednorazowy; ważność widoczna przy linku i w wierszu.    | PRD 4.10, US-07                 |
| Unieważnienie pyta z datą ważności linku i czasownikiem „Unieważnij link”. | wzorzec potwierdzenia usunięcia |

## 10. API

Wzorzec składa gotowe komponenty: `InviteLinkPanel`, `InvitationRow`, `ConfirmDeleteDialog`, `JoinBudgetCard`, `SignInForm` (`notice`). Ich API opisują strony komponentów.

## 11. Kod

```tsx
<InviteLinkPanel
  link={invite.data?.link}
  expiresOn={invite.data?.expiresOn}
  generating={invite.isPending}
  error={invite.isError ? "Nie udało się wygenerować linku. Spróbuj ponownie." : undefined}
  onGenerate={() => invite.mutate()}
  onCopy={() =>
    navigator.clipboard.writeText(invite.data.link).then(() => showToast("Skopiowano link"))
  }
/>;
{
  invitations.data?.map((row) => (
    <InvitationRow
      key={row.id}
      expiresOn={row.expiresOn}
      createdBy={row.createdBy}
      onRevoke={isOwner ? () => setRevoking(row) : undefined}
    />
  ));
}
```

## 12. Dobrze i źle

| Dobrze                                    | Źle                                                |
| ----------------------------------------- | -------------------------------------------------- |
| Link dopiero po „Wygeneruj link”.         | Stały link w ustawieniach, który nigdy nie wygasa. |
| Unieważnienie z pytaniem i datą ważności. | „Usuń” bez informacji, który link znika.           |

## 13. Powiązane

- Komponenty: panel linku zaproszenia, wiersz zaproszenia, karta dołączenia.
- Wzorce: potwierdzenie usunięcia, logowanie kodem.
