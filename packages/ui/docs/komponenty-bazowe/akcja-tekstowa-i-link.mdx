# Akcja tekstowa i link

`import { Button } from "@koperty/ui/primitives/button";` – `variant="link"`, a dla przejść `asChild` z `<a>` albo linkiem routera.

## 1. Do czego służy

Daje dostęp do mniej ważnej czynności albo innego miejsca w aplikacji bez wizualnej wagi przycisku.

## 2. Kiedy używać

| Sytuacja w produkcie                                             | Element                                                                  | Źródło             |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------------ |
| „Wyślij nowy kod” na ekranie logowania                           | akcja tekstowa: `Button variant="link"`                                  | S-01 (AC-3)        |
| Nazwa użytkownika w nagłówku prowadząca do profilu               | link: `Button asChild variant="link"` z linkiem routera                  | S-01 (nagłówek)    |
| Odnośnik w zdaniu („zmienisz w ustawieniach profilu”)            | link z `size="inline"`                                                   | propozycja (E2-P4) |
| Przejście, które ma wyglądać jak przycisk („Przejdź do budżetu”) | `Button asChild variant="primary"` z `<a>`: wygląd przycisku, rola linku | WAI-ARIA (link)    |

## 3. Kiedy nie używać

| Zamiast                                               | Użyj                                      | Źródło       |
| ----------------------------------------------------- | ----------------------------------------- | ------------ |
| Główna czynność formularza                            | przycisk `primary`                        | E2-P4        |
| Czynność, która coś zmienia nieodwracalnie            | przycisk otwierający dialog potwierdzenia | US-06, US-03 |
| Link bez podkreślenia, rozpoznawalny tylko po kolorze | zawsze z podkreśleniem                    | WCAG 1.4.1   |

## 4. Anatomia

| Część             | Opcjonalna | Uwagi                                                                   |
| ----------------- | ---------- | ----------------------------------------------------------------------- |
| Tekst             | nie        | `text-label`, `text-link`, podkreślony                                  |
| Ikona             | tak        | tylko gdy link otwiera coś poza aplikacją (wtedy z opisem dla czytnika) |
| Obszar kliknięcia | nie        | 40 px wysokości (`default`), w zdaniu – wysokość linii tekstu           |

## 5. Warianty

| Element                          | Kiedy wybrać                                            |
| -------------------------------- | ------------------------------------------------------- |
| `variant="link"` jako `<button>` | czynność na tym ekranie (wysłanie kodu ponownie)        |
| `variant="link" asChild` z `<a>` | przejście na inny adres                                 |
| `size="inline"`                  | link w środku zdania, bez wysokości i wnętrza kontrolki |

## 7. Zachowanie i dostępność

| Zasada                                                                                                                            | Źródło                  |
| --------------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| Link (`<a href>`) zmienia adres i otwiera się Enterem; przycisk (`<button>`) wykonuje czynność Enterem i Spacją. Nie mieszaj ról. | WAI-ARIA (link, button) |
| Tekst linku mówi, dokąd prowadzi; nie „kliknij tutaj”.                                                                            | WCAG 2.4.4              |
| Cel kliknięcia samodzielnej akcji: 40 px. Link w zdaniu jest zwolniony z minimum 24 px.                                           | WCAG 2.5.8              |

## 8. Treść

| Zasada                               | Przykład                 | Źródło                   |
| ------------------------------------ | ------------------------ | ------------------------ |
| Akcja tekstowa: czasownik i obiekt   | „Wyślij nowy kod”        | polecenie budowy (Treść) |
| Link w zdaniu: nazwa celu, 1–4 słowa | „w ustawieniach profilu” | WCAG 2.4.4               |
| Długi tekst się zawija, nie skraca   | –                        | WCAG 1.4.10              |

## 10. API

Ten sam komponent co Przycisk; istotne propsy: `variant="link"`, `size` (`default`, `sm`, `inline`), `asChild`. Pełna tabela: strona „Przycisk”.

## 11. Kod

Minimalny:

```tsx
<Button variant="link" onClick={resend}>
  Wyślij nowy kod
</Button>
```

Typowy w produkcie (nagłówek, S-01):

```tsx
<Button asChild variant="link">
  <Link to="/profile">{profile.display_name}</Link>
</Button>
```

## 13. Powiązane

- Mylona z: **przyciskiem** (czynność główna), **zakładkami** (przełączanie widoków w miejscu).
- Występuje we wzorcach: logowanie kodem w dwóch krokach, nagłówek aplikacji.
