# Przycisk

`import { Button } from "@koperty/ui/primitives/button";`

## 1. Do czego służy

Uruchamia czynność na bieżącym ekranie: zapisuje, wysyła, otwiera dialog, usuwa.

## 2. Kiedy używać

| Sytuacja w produkcie                                                                        | Wariant                 | Źródło                             |
| ------------------------------------------------------------------------------------------- | ----------------------- | ---------------------------------- |
| Wysłanie formularza: „Zapisz wydatek”, „Wyślij kod”, „Utwórz budżet”                        | `primary`               | US-17, US-01, US-04                |
| Rezygnacja albo czynność drugorzędna obok głównej: „Anuluj”, „Edytuj”                       | `secondary`             | propozycja (E2-P4)                 |
| Akcja w wierszu listy lub nagłówku karty, często sama ikona: „Usuń wydatek”, „Więcej akcji” | `ghost` z `size="icon"` | US-19, R01.3                       |
| Potwierdzenie nieodwracalnej operacji w dialogu potwierdzenia: „Usuń budżet”                | `danger`                | tokeny.md (`action-danger`), US-06 |

## 3. Kiedy nie używać

| Zamiast przycisku                           | Użyj                                                                                 | Źródło                     |
| ------------------------------------------- | ------------------------------------------------------------------------------------ | -------------------------- |
| Przejście na inny ekran (adres się zmienia) | link: `Button asChild` z `<a>` albo linkiem routera – strona „Akcja tekstowa i link” | WAI-ARIA (link a przycisk) |
| Mała czynność w tekście („Wyślij nowy kod”) | wariant `link`                                                                       | propozycja (E2-P4)         |
| Włączenie lub wyłączenie ustawienia         | Przełącznik                                                                          | WAI-ARIA (switch)          |
| `danger` poza dialogiem potwierdzenia       | `ghost` lub `secondary` otwierające dialog potwierdzenia                             | tokeny.md, AC4             |
| `div` lub `span` z `onClick`                | zawsze `Button` (rola, fokus i klawiatura są wbudowane)                              | WCAG 2.1.1, 4.1.2          |

## 4. Anatomia

| Część                | Opcjonalna                            | Uwagi                                                 |
| -------------------- | ------------------------------------- | ----------------------------------------------------- |
| Kontener (`button`)  | nie                                   | 40 px wysokości, promień `radius-control` (W1, R01.3) |
| Etykieta             | nie (przy samej ikonie: `aria-label`) | `text-label` 14 px / 500 (P3)                         |
| Ikona przed etykietą | tak                                   | 16 px, `aria-hidden="true"` (Fundamenty / Ikony)      |
| Wskaźnik ładowania   | tylko przy `loading`                  | zastępuje widok etykiety, szerokość bez zmian (E2-Q2) |

## 5. Warianty

<Canvas of={Stories.Warianty} />
<Canvas of={Stories.Rozmiary} />

| Wariant lub rozmiar | Kiedy wybrać                                                        |
| ------------------- | ------------------------------------------------------------------- |
| `primary`           | jedna główna czynność sekcji lub ekranu (E2-P4)                     |
| `secondary`         | czynność drugorzędna obok głównej, rezygnacja                       |
| `ghost`             | akcje w wierszach i nagłówkach, gdzie pełne tło byłoby zbyt ciężkie |
| `danger`            | tylko przycisk potwierdzający usunięcie w dialogu potwierdzenia     |
| `link`              | akcja tekstowa (opis na stronie „Akcja tekstowa i link”)            |
| `default` (40 px)   | wszędzie, także na telefonie (W1, K1)                               |
| `sm` (32 px)        | akcje w wierszu listy lub tabeli (P2)                               |
| `icon`, `icon-sm`   | przycisk z samą ikoną; zawsze z `aria-label`                        |
| `inline`            | tylko z `link`, wewnątrz zdania                                     |

## 6. Stany

Najechanie, fokus i wciśnięcie są pokazane jako zamrożony podgląd (te same deklaracje co w `:hover`, `:focus-visible` i `:active`).

<Canvas of={Stories.Stany} />

| Stan          | Wygląd                                                                                                                   | Źródło         |
| ------------- | ------------------------------------------------------------------------------------------------------------------------ | -------------- |
| Domyślny      | kolor wariantu                                                                                                           | R01.2          |
| Najechanie    | `*-hover`, bez zmiany kształtu                                                                                           | K2             |
| Fokus         | linia 2 px `focus-ring` z odstępem 2 px                                                                                  | W2, WCAG 2.4.7 |
| Wciśnięty     | `primary`: `action-primary-pressed`, `ghost`: `action-secondary-hover`; pozostałe: kolor najechania; bez przesunięcia    | K2, AC1        |
| Zablokowany   | przezroczystość 50%, nie reaguje; obok zawsze tekst, dlaczego akcja jest niedostępna, powiązany przez `aria-describedby` | E2-Q1          |
| Ładowanie     | wskaźnik i tekst czynności w toku („Zapisywanie…”), `aria-busy`, kolejne kliknięcia ignorowane                           | E2-Q2          |
| Wybrany, błąd | nie dotyczy: przycisk nie ma stanu wyboru ani błędu (do tego służy przełącznik i pole formularza)                        | –              |

**Jak użytkownik dowie się, dlaczego akcja jest zablokowana:** tekst pod przyciskiem mówi, czego brakuje i jaki jest stan teraz. Przycisku wysyłania formularza nie blokujemy – po kliknięciu walidacja pokazuje, co poprawić (E2-Q1).

## 7. Zachowanie i dostępność

| Zasada                                                                                         | Źródło                    |
| ---------------------------------------------------------------------------------------------- | ------------------------- |
| Rola `button`; Enter i Spacja uruchamiają czynność (sprawdza test w story Playground).         | WAI-ARIA (button pattern) |
| Kolejność fokusu zgodna z kolejnością w kodzie; nie używaj `tabindex` dodatniego.              | WCAG 2.4.3                |
| Przycisk z samą ikoną ma `aria-label` z czasownikiem i obiektem.                               | WCAG 4.1.2                |
| Czytnik ogłasza etykietę i rolę; przy ładowaniu „Zapisywanie…” i stan zajętości (`aria-busy`). | WAI-ARIA                  |
| Zablokowany przycisk ma `disabled` i `aria-describedby` wskazujące wyjaśnienie.                | E2-Q1, WCAG 1.3.1         |
| Cel kliknięcia: 40 px (`sm` 32 px), więcej niż wymagane 24 × 24 px.                            | WCAG 2.5.8                |
| W formularzu przycisk wysyłania ma `type="submit"`, pozostałe `type="button"`.                 | HTML, standardy 4.5       |

## 8. Treść

| Zasada                                                                                                                                          | Przykład                                                        | Źródło                   |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------ |
| Czasownik i obiekt, w bezokoliczniku lub trybie rozkazującym                                                                                    | „Zapisz wydatek”, „Usuń budżet”, nigdy „OK”                     | polecenie budowy (Treść) |
| Najwyżej 3 słowa, około 24 znaków; etykieta się nie zawija                                                                                      | „Wygeneruj link zaproszenia” (26 znaków) to granica             | propozycja (E2-P2)       |
| Tekst ładowania opisuje czynność w toku i nie jest dłuższy od etykiety (przycisk zachowuje szerokość); bez krótkiego tekstu pomiń `loadingText` | „Zapisz wydatek” → „Zapisywanie…”, „Usuń wydatek” → „Usuwanie…” | E2-Q2                    |
| Liczby i kwoty nie trafiają do etykiety                                                                                                         | „Dodaj przydział”, a kwota w polu obok                          | propozycja (E2-P2)       |
| Tłumaczenie: przy dłuższym języku etykieta nadal mieści się na 320 px, bo na telefonie przyciski formularza mają pełną szerokość                | –                                                               | DS-S02                   |

## 10. API

<ArgTypes of={Stories} />

| Prop          | Typ                                                         | Domyślnie   | Opis                                                    |
| ------------- | ----------------------------------------------------------- | ----------- | ------------------------------------------------------- |
| `variant`     | `"primary" \| "secondary" \| "ghost" \| "danger" \| "link"` | `"primary"` | wygląd według roli                                      |
| `size`        | `"default" \| "sm" \| "icon" \| "icon-sm" \| "inline"`      | `"default"` | wysokość i wnętrze                                      |
| `loading`     | `boolean`                                                   | `false`     | ładowanie: wskaźnik, `aria-busy`, kliknięcia ignorowane |
| `loadingText` | `string`                                                    | etykieta    | tekst w trakcie ładowania                               |
| `asChild`     | `boolean`                                                   | `false`     | wygląd przycisku na elemencie potomnym (np. link)       |
| pozostałe     | atrybuty `<button>`                                         | –           | `type`, `disabled`, `onClick`, `aria-*`                 |

## 11. Kod

Minimalny:

```tsx
<Button onClick={save}>Zapisz wydatek</Button>
```

Typowy w produkcie (formularz wydatku, US-17):

```tsx
<div className="flex flex-col gap-group md:flex-row">
  <Button
    type="submit"
    loading={mutation.isPending}
    loadingText="Zapisywanie…"
    className="w-full md:w-auto"
  >
    Zapisz wydatek
  </Button>
  <Button type="button" variant="secondary" onClick={onCancel} className="w-full md:w-auto">
    Anuluj
  </Button>
</div>
```

## 13. Powiązane

- Mylony z: **akcją tekstową i linkiem** (link zmienia adres, przycisk wykonuje czynność), **przełącznikiem** (stan, nie czynność).
- Występuje we wzorcach: formularz, potwierdzenie usunięcia, lista z filtrem miesiąca.
