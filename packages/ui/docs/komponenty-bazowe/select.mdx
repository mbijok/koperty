# Select

`import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from "@koperty/ui/primitives/select";`

## 1. Do czego służy

Pozwala wybrać jedną wartość z krótkiej, znanej listy bez wpisywania, np. kopertę wydatku.

## 2. Kiedy używać

| Sytuacja w produkcie                                       | Źródło                                                               |
| ---------------------------------------------------------- | -------------------------------------------------------------------- |
| Koperta wydatku (jedna koperta)                            | US-17                                                                |
| Koperta w każdej części podziału wydatku                   | US-18                                                                |
| Wybór budżetu na ekranie ustawień, jeśli lista jest krótka | US-05 (propozycja; przełącznik budżetu w nagłówku to menu, partia 2) |

## 3. Kiedy nie używać

| Sytuacja                                               | Zamiast                                                      | Źródło             |
| ------------------------------------------------------ | ------------------------------------------------------------ | ------------------ |
| Więcej niż około 15 pozycji albo potrzeba wyszukiwania | pole z wyszukiwaniem (brak w planie, strona „Czego brakuje”) | propozycja (E2-P6) |
| Dwie wartości: tak/nie                                 | Przełącznik                                                  | WAI-ARIA (switch)  |
| Akcje (edytuj, usuń)                                   | menu (partia 2)                                              | WAI-ARIA (menu)    |
| Wartość wpisywana (kwota, nazwa)                       | Pole tekstowe                                                | –                  |

## 4. Anatomia

| Część                                   | Opcjonalna | Uwagi                                                   |
| --------------------------------------- | ---------- | ------------------------------------------------------- |
| Przycisk otwierający (`SelectTrigger`)  | nie        | wygląd pola tekstowego, 40 px, strzałka 16 px           |
| Wartość lub placeholder (`SelectValue`) | nie        | placeholder: „Wybierz kopertę” w `text-muted`           |
| Lista (`SelectContent`)                 | nie        | nakładka `surface-overlay`, `shadow-overlay`, w portalu |
| Pozycja (`SelectItem`)                  | nie        | 40 px, znacznik wyboru na końcu                         |
| Przyciski przewijania                   | tak        | pojawiają się, gdy lista się nie mieści                 |

## 5. Warianty

Jeden wariant; rozmiar jak pole tekstowe (W1).

**Wyjątek dostępności (opisany):** story „Otwarty” wyłącza regułę axe `aria-hidden-focus`. Gdy lista jest otwarta, Radix ukrywa resztę strony (`aria-hidden`) i przenosi fokus do listy; statyczny zrzut nadal widzi fokusowalny przycisk pod `aria-hidden`, czego w działaniu nie ma. Test interakcji w Playground sprawdza, że fokus wraca na przycisk po wyborze.

## 7. Zachowanie i dostępność

| Zasada                                                                                                                                  | Źródło                          |
| --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| Rola `combobox` (select-only) z listą `listbox`; Enter, Spacja i strzałki otwierają, strzałki przesuwają, Enter wybiera, Escape zamyka. | WAI-ARIA (select-only combobox) |
| Po wyborze fokus wraca na przycisk (sprawdza test w Playground).                                                                        | WCAG 2.4.3                      |

## 10. API

<ArgTypes of={Stories} />

`Select` przyjmuje propsy `Select.Root` z Radix (`value`, `defaultValue`, `onValueChange`, `disabled`, `name`); `SelectTrigger` – `id`, `aria-invalid`; `SelectItem` – `value`, `disabled`.

## 11. Kod

Minimalny:

```tsx
<FormField label="Koperta">
  {(control) => (
    <Select value={envelopeId} onValueChange={setEnvelopeId}>
      <SelectTrigger {...control}>
        <SelectValue placeholder="Wybierz kopertę" />
      </SelectTrigger>
      <SelectContent>
        {envelopes.map((envelope) => (
          <SelectItem key={envelope.id} value={envelope.id}>
            {envelope.name}
          </SelectItem>
        ))}
      </SelectContent>
    </Select>
  )}
</FormField>
```

Typowy w produkcie: ten sam kod w formularzu wydatku (US-17); zarchiwizowanych kopert nie ma na liście (US-13).

## 13. Powiązane

- Mylony z: **menu** (lista akcji), **przełącznikiem** (dwie wartości), **polem z wyszukiwaniem** (brak w planie).
- Występuje we wzorcach: formularz, podział wydatku.
