# Odstępy i układ

Zwartość (C1) robią odstępy, a nie małe kontrolki (K1). Odstęp wybierasz według relacji między elementami, a nie według liczby pikseli. Numeryczna skala odstępów Tailwinda (`p-4`, `gap-2`) jest wyłączona; istnieją tylko klasy z tokenów.

## Reguła relacji

Im bliżej związane elementy, tym mniejszy odstęp. Każdy poziom ma jeden token.

| Sytuacja w produkcie                                        | Token                  | Klasa                |
| ----------------------------------------------------------- | ---------------------- | -------------------- |
| Ikona obok tekstu w przycisku, kwota obok znacznika „Debet” | `space-inline`         | `gap-inline`         |
| Etykieta, pole i podpowiedź jednego pola formularza         | `space-group`          | `gap-group`          |
| Kolejne pola formularza, kolejne karty kopert na liście     | `space-between-groups` | `gap-between-groups` |
| Wnętrze karty puli, dialogu potwierdzenia                   | `space-panel`          | `p-panel`            |
| Wnętrze wiersza operacji na liście                          | `space-panel-compact`  | `p-panel-compact`    |
| Między sekcją „Do rozdysponowania” a listą kopert           | `space-section`        | `gap-section`        |

Źródło wartości: P4 (z odstępów R01.5).

## Układ

Projekt jest mobile first (DS-S02): najpierw układ dla 320 px, szersze ekrany tylko poszerzają marginesy i ograniczają szerokość treści.

<Unstyled>
  <TokenTable caption="Tokeny układu" rows={layoutTokens} />
</Unstyled>

| Szerokość | Zachowanie                                                                                                      | Źródło              |
| --------- | --------------------------------------------------------------------------------------------------------------- | ------------------- |
| 320 px    | jedna kolumna, margines `px-gutter` (16 px), bez poziomego przewijania strony; długie nazwy kopert się zawijają | DS-S02, WCAG 1.4.10 |
| 768 px    | margines `md:px-gutter-wide` (24 px), treść wyśrodkowana w `max-w-content` (640 px)                             | P5                  |
| 1440 px   | jak 768 px; tylko tabela podsumowania miesiąca rozszerza się do `max-w-content-wide` (960 px)                   | P5                  |

Pozioma przewijalność dopuszczalna jest tylko wewnątrz tabeli podsumowania miesiąca na wąskim ekranie (tabela ma przewijany kontener), nigdy dla całej strony (WCAG 1.4.10).

Punkt przełączenia: domyślny `md` Tailwinda (768 px). Inne punkty nie są używane (P5).
